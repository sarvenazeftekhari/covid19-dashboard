📊 Insights

The chart above shows monthly COVID-19 data for the selected country. Select a different country or metric using the dropdowns.

Key trends observed: Vaccination rollouts typically began in early 2021. You can see that sometimes there is a large spike in reported vaccinations because of the campaign drives. New deaths generally lagged new cases by several weeks.

Design choices: Missing values were filled with 0 because no report probably means no confirmed cases that period. Extreme spikes above the 99th percentile per country were capped to reduce visual distortion from data-entry anomalies. A smooth line chart was chosen over bar charts to emphasize trend over time. Colors use high-contrast palettes for readability.

⚠️ Correlation ≠ Causation: Rising vaccinations alongside rising cases in some periods does not mean vaccines caused cases because both were driven by independent factors like reporting changes and population behavior. Always consider confounding variables before drawing conclusions from this data.
Data: Our World in Data COVID-19 Dataset (Sample)
